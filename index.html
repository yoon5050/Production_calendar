📦 생산 캘린더

날짜 클릭 → 오른쪽 패널에서 생산 기록 입력·연구노트 체크·휴무 지정. 초록=오늘까지 생산분, 파랑=직접 입력한 예정, 파란 점선=생산 발주에 따른 자동 예정, 주황=자재 입고, 📓=연구노트 작성 여부.

🏭 생산 발주 — 생산 공장에 보내는 제작 요청 (무엇을 몇 개, 어떤 순서로)

예상 완료일은 제품별 하루 생산량(제품·배합 탭)과 휴무일 기준으로, 위 우선순위 순서대로 한 줄로 생산한다고 가정해 계산됩니다 (제품이 바뀌면 그날 남은 가동분만큼 이어서 생산). 실제 생산 기록이 쌓이면 잔여 수량이 자동으로 줄어듭니다. 업체와 협의가 끝나면 위의 ✅ 생산 발주 확정을 눌러 캘린더에 일정을 반영하세요.

🗂 지난 생산 발주

발주 마감을 누르면 그 시점의 제작 순서가 날짜별로 여기에 보관되고, 새 발주를 깨끗한 상태에서 시작할 수 있어요. 보관된 발주를 이어서 진행하려면 ↩️ 복원을 누르세요.

♻️ 이 탭은 재료(플레이크·파우더)를 자재 업체에 주문하는 곳이에요. 생산 공장에 보내는 제작 요청은 생산 발주 🏭 탭에서.
흐름: ① 생산 발주 등록 → ② 자재 필요량이 자동 계산되면 발주서 인쇄·전송 → ③ 희망 입고일 지정 후 아래 "배합 발주 확정"을 누르면 캘린더에 📦 입고 예정이 자동 등록되고 → ④ 생산 시작일을 입고일로 설정하면 자동 생산 일정이 그날부터 캘린더에 깔립니다.

① 발주서 — 춘천자활센터 (색상 배합 발주)

자재 발주는 춘천자활센터에서 배합까지 진행하는 기준입니다. 포대 수는 1포대 = kg 기준 올림 계산. 발주서 인쇄 시 뒷장에 플레이크별 필요량 합계와 배합비가 자동으로 함께 인쇄됩니다.

🧪 테스트 / 샘플 제작 요청

새로운 소재로 샘플을 제작할 때 소재 정보와 배합을 정리해 공장에 전달하는 요청서입니다. 재료명은 자유롭게 입력 가능하고, 작성 후 복사 또는 인쇄로 전달하세요.

제품 · 색상 · 배합 관리

색상마다 개당 소요 kg과 배합비(%)를 등록하면 발주 탭에서 플레이크 필요량이 자동 계산됩니다. 배합 합계는 100%가 되어야 해요.

색상별 재고 — 춘천 발주 10kg 포대 기준

재고 입력 →

춘천에서 색상 배합 포대(10kg)로 입고되는 기준의 재고예요. 포대 수와 입고일을 입력하면 그 날짜로 반영되고(비워두면 오늘), 입고일이 미래면 '입고 예정'으로, 지나면 보유 재고에 합산됩니다. 이후 생산 기록만큼 자동 차감돼요. 같은 색상에 다시 입력하면 이전 직접 입력분은 교체됩니다.

발주처 관리

색상 배합 발주 유형(예: 춘천자활센터)은 발주 탭에서 색상별 배합표 + 포대 수 형식의 발주서가 만들어지고, 플레이크 단품 유형은 자재별 kg/포대 발주서가 만들어집니다.

🔑 Firebase 설정 붙여넣기 (이 칸이 제일 쉬워요)

여기에 한 번 저장하면 이 브라우저(기기)에 기억돼서, 앞으로 새 파일로 바꿔도 다시 입력할 필요 없어요. 붙여넣을 때 <script> 줄이 섞여 있어도 자동으로 걸러냅니다.

필요 사전 작업(최초 1회, 무료): ① console.firebase.google.com에서 프로젝트 생성 → ② Authentication에서 Google 로그인 사용 설정 → ③ Firestore 데이터베이스 생성(서울) + 규칙에 @lowlit.co 제한 게시 → ④ 프로젝트 설정에서 firebaseConfig 복사 → 위 칸에 붙여넣고 저장 → ⑤ 배포 주소를 Authentication 승인된 도메인에 추가.
